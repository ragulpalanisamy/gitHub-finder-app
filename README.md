# 🚀 GitHub Finder App

> A modern, responsive web application to discover and explore GitHub developers with advanced search capabilities and beautiful UI.

[![React](https://img.shields.io/badge/React-18.2.0-blue.svg)](https://reactjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue.svg)](https://www.typescriptlang.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.3-blue.svg)](https://tailwindcss.com/)
[![Vite](https://img.shields.io/badge/Vite-4.5-build.svg)](https://vitejs.dev/)
[![Mobile First](https://img.shields.io/badge/Mobile%20First-Responsive-green.svg)](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Responsive)

## ✨ Features

- 🔍 **Advanced Search**: Find GitHub users with real-time API integration
- 📱 **Mobile First**: Fully responsive design for all devices
- 🌙 **Dark/Light Theme**: Toggle between themes with persistent preferences
- 🎯 **Popular Developers**: Explore trending developers and contributors
- 🔧 **Smart Filters**: Sort by followers, repos, join date, and more
- 📊 **Rich Profiles**: Detailed user statistics and information
- ⚡ **Performance**: Built with Vite for lightning-fast development
- 🎨 **Modern UI**: Glass morphism effects and smooth animations

## 🛠️ Tech Stack

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS + PostCSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Package Manager**: npm

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/yourusername/github-finder-app.git
cd github-finder-app

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 📱 Mobile Responsiveness

The app is built with a **mobile-first approach** and supports:

- 📱 **Mobile**: 320px - 639px (touch-optimized)
- 📱 **Tablet**: 640px - 1023px (balanced layout)
- 🖥️ **Desktop**: 1024px+ (full-featured)
- 🖥️ **Large Screens**: 1280px+ (ultra-wide support)

## 🎯 Key Components

- **Header**: Responsive navigation with mobile menu
- **SearchSection**: Hero section with advanced search
- **Popular Developers**: Grid of trending developers

- **User Profiles**: Rich GitHub profile display
- **Theme Toggle**: Dark/light mode switcher
